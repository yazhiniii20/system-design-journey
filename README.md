# System Design Journey

Welcome to my System Design learning repository.

I'm learning how scalable backend systems are designed by studying core concepts and implementing them using Java and Spring Boot. This repository contains notes, architecture diagrams, and hands-on implementations of real-world system design patterns.

## Topics I'll cover

- Client–Server Architecture
- Load Balancing
- Caching (Redis)
- Database Design & Indexing
- SQL vs NoSQL
- Message Queues
- API Gateway
- Rate Limiting
- Microservices
- Distributed Systems
- Scalability & Reliability

The goal is to understand not just the theory, but also how these concepts are implemented in production-style backend applications.
